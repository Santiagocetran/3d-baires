# Reportar un problema de seguridad

Si encontrás una vulnerabilidad en 3d-baires, usá [Report a vulnerability en GitHub](https://github.com/Santiagocetran/3d-baires/security/advisories/new). Los reportes privados están habilitados para este repositorio.

Describí el problema, su posible impacto y los pasos para reproducirlo. Podés incluir un ejemplo mínimo con datos ficticios. No publiques contraseñas, tokens, datos personales ni instrucciones con credenciales reales en issues, pull requests o capturas.

Para errores visuales, sugerencias o problemas con los datos públicos del mapa, podés usar los [issues habituales](https://github.com/Santiagocetran/3d-baires/issues).

La revisión se centra en la rama `master` y la [versión pública](https://3d-baires.vercel.app). Los escaneos y auditorías detectan ciertos problemas conocidos; no constituyen una garantía de ausencia de vulnerabilidades. La evidencia de la revisión previa a compartir el proyecto está en [docs/security-review.md](docs/security-review.md).
